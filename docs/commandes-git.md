# Commandes Git indispensables

## Observer

```bash
git status
git log --oneline
```

## Sauvegarder une étape

```bash
git add .
git commit -m "jour 01 : terminer le niveau 1"
```

## Envoyer sur GitHub

```bash
git push
```

## Récupérer son dépôt sur un nouveau poste

```bash
git clone URL_DE_TON_DEPOT
```

## Bons messages de commit

```text
jour 02 : terminer les exercices 01 à 07
jour 04 : corriger la validation email
jour 07 : terminer le challenge final
```

Évite les messages vagues comme `test`, `update` ou `final`.
